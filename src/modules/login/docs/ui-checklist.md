# UI Checklist

Use this checklist before submitting a feature for review.

---

## Visual

- [ ] Colors, Typography, Pseudo, Animation use design tokens.
- [ ] Clear hierarchical layout
- [ ] Icons are aligned and sized correctly.

---

## States

### Loading

- [ ] Button loading state is visible.
- [ ] Button loading control are disabled when appropriate.

### Empty

- [ ] Empty state is handled.
- [ ] Empty message is meaningful.

### Error

- [ ] Error state is displayed clearly.
- [ ] Error message is understandable.
- [ ] Recovery action is available if applicable.

### Success

- [ ] Success feedback is shown when necessary.

---

## Form

- [ ] Required fields are clearly indicated.
- [ ] Validation messages are correct.
- [ ] Validation appears at the correct time.
- [ ] Submit button behaves correctly.
- [ ] Keyboard navigation works.
- [ ] Password visibility toggle works (if applicable).

---

## Interaction

- [ ] Hover states are implemented.
- [ ] Focus states are visible.
- [ ] Active states are correct.
- [ ] Disabled states are distinguishable.
- [ ] Click targets are large enough.
- [ ] Transitions feel smooth.

---

## Navigation

- [ ] Links navigate correctly.
- [ ] Back navigation works.
- [ ] Redirects are correct.
- [ ] Protected routes behave correctly.

---

## Responsive

- [ ] Mobile layout.
- [ ] Tablet layout.
- [ ] Desktop layout.
- [ ] No horizontal scrolling.
- [ ] Sticky elements behave correctly.

---

## Accessibility

- [ ] Interactive elements are keyboard accessible.
- [ ] Labels are associated with inputs.
- [ ] Images have alt text.
- [ ] Color contrast is acceptable.
- [ ] Focus order is logical.

---

## Feedback

- [ ] Toasts appear when expected.
- [ ] Modals open and close correctly.
- [ ] Confirmation dialogs are shown when needed.

---

## Theme

- [ ] Light theme.
- [ ] Dark theme.
- [ ] Theme switching works correctly.

---

## Polish

- [ ] No console errors.
- [ ] No obvious visual glitches.
- [ ] Text is free of typos.
- [ ] Animations are consistent.
- [ ] Overall UI feels polished.
